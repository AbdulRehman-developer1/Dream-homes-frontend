🏡 Dream Homes - Frontend Website

A responsive and modern construction & real estate website built using HTML, CSS, JavaScript, and Bootstrap. This project is designed to showcase beautiful house designs, construction services, and property listings with a clean UI.

🌟 Features

Fully responsive design (mobile, tablet, desktop)

Modern homepage layout : 

Property / house showcase section
